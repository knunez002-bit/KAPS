# KAPS — Sitio web para GitHub

Proyecto front-end basado visualmente en la referencia proporcionada para KAPS.

## Páginas
1. `index.html` — Registro + información de la aplicación.
2. `vacantes.html` — Vacantes/proyectos, compensaciones y detalles.
3. `comunidad.html` — Comentarios y redes sociales.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Bootstrap Icons
- Google Fonts (Inter)

## Bootstrap
Cada página incluye Bootstrap por CDN y utiliza componentes/herramientas como navbar responsive, botones, grid, input groups, badges, modal, formularios y validación.

## JavaScript
Incluye:
- Validación de formularios.
- Buscador de vacantes.
- Modal de detalles de vacantes.
- Menú responsive.

Los datos son demostrativos. Los formularios pueden conectarse posteriormente a una API RESTful.
